# Contributing

Work from a feature branch and open a pull request for review. Keep commits focused and use conventional prefixes such as `feat:`, `fix:`, `test:`, `docs:`, and `chore:`.

Every change should include:

- a short description of the behavior changed
- tests or a reason tests are not applicable
- API or database migration notes when relevant
- screenshots for frontend changes

Keep each implementation phase runnable. Do not add real land records, personal data, credentials, or unapproved government data.
